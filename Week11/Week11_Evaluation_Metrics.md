# Week 11 Lab – Evaluation Metrics

## Overview

This file outlines the **evaluation metrics** to be used for assessing student submissions of **Week 11 Lab**.  
The assessment focuses on **correctness, efficiency, code quality, OOP design, and analysis**.  

Each submission will be graded out of **75 marks**, distributed across the 3 lab questions.

### **Q1. Graph Construction (20 marks)**
- **Correct Graph Representation (Adjacency List/Matrix):** 8 marks  
- **Support for Add/Remove Stations & Routes:** 4 marks  
- **CSV Import Functionality:** 4 marks  
- **Code Quality & Encapsulation (OOP principles):** 4 marks  

---

### **Q2. Dijkstra Shortest Path (25 marks)**
- **Correct Implementation of Dijkstra’s Algorithm:** 10 marks  
- **Shortest Path (Single Source to Destination) Correctness:** 5 marks  
- **All-Pairs (Source to All Stations) Correctness:** 5 marks  
- **Efficient Use of Heap/Priority Queue:** 3 marks  
- **Code Modularity & Documentation:** 2 marks  

---

### **Q3. Minimum Spanning Tree (30 marks)**
- **Correct Implementation of Prim’s Algorithm:** 8 marks  
- **Correct Implementation of Kruskal’s Algorithm (with DSU):** 8 marks  
- **Correct MST Edge Set & Cost Calculation:** 6 marks  
- **Comparison/Analysis of Prim vs Kruskal:** 4 marks  
- **Code Structure & Reusability:** 4 marks
