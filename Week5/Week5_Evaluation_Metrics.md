# Week 5 Lab: Evaluation Metrics

Use the following metrics to evaluate submissions for the Week 5 Lab on Algorithm Analysis and Search Implementations.

---

## 1. Code Implementation (40%)

- **Correctness (20%)**
  - Linear search and binary search functions are implemented correctly.
  - Functions return correct indices or -1 for not found.
- **Completeness (10%)**
  - All required functions (including benchmarking, hybrid search, and file-based search) are implemented.
- **Code Quality (10%)**
  - Code is readable, well-structured, and uses meaningful variable/function names.
  - Proper use of comments and docstrings.

---

## 2. Benchmarking and Analysis (25%)

- **Benchmarking (10%)**
  - Benchmarking code runs without errors and produces meaningful results.
  - Results are plotted and visualized clearly.
- **Analysis (10%)**
  - Student provides a brief analysis of the observed results (e.g., log-log plots, performance trends).
- **Edge Cases (5%)**
  - Edge cases (e.g., empty list, key not present) are handled and discussed.

---

## 3. Practical Exercises (20%)

- **File-based Search (10%)**
  - Function to search in file-based datasets is implemented and tested.
  - Timing and comparison between linear and binary search are provided.
- **Hybrid Search (10%)**
  - Hybrid/adaptive search logic is implemented as per instructions.
  - Benchmarks and comparison with traditional approaches are included.

---

## 4. Reflection and Discussion (10%)

- **Summary Questions (10%)**
  - Student answers all reflection questions thoughtfully:
    - Trade-offs between linear and binary search.
    - Differences between theoretical and actual performance.
    - Real-world scenarios for linear search.
    - Design ideas for large-scale/networked search systems.

---

## 5. Optional Challenge (Bonus: up to 5%)

- **Interpolation Search**
  - Correct implementation and benchmarking of interpolation search.
  - Comparison with binary search on uniformly distributed data.

---

## Grading Rubric

| Criteria                      | Points |
|-------------------------------|--------|
| Code Implementation           |   40   |
| Benchmarking & Analysis       |   25   |
| Practical Exercises           |   20   |
| Reflection & Discussion       |   10   |
| Optional Challenge (Bonus)    |   +5   |
| **Total**                     | **100**|

---

**Note:** Partial credit can be awarded for incomplete or partially correct solutions. Encourage clear explanations and well-documented.
