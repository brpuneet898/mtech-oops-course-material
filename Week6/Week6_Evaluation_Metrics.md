# Week 6 Lab: Insertion & Selection Sort  

## Evaluation Metrics

| Criteria                                      | Excellent (4)                | Good (3)                  | Satisfactory (2)           | Needs Improvement (1)      |
|-----------------------------------------------|------------------------------|---------------------------|----------------------------|----------------------------|
| **Algorithm Implementation**                  | Both sorts correct, clear, and well-commented | Both sorts correct, minor issues | One sort correct, or both with issues | Major errors or missing code |
| **Verbose Output / Dry Run**                  | Step-by-step output is clear and matches logic | Step-by-step output mostly clear | Output present but lacks clarity | Output missing or incorrect |
| **Time Complexity Analysis & Plot**           | Accurate timing, clear plot, correct labels | Timing and plot mostly correct | Plot present but unclear or mislabeled | Missing or incorrect plot |
| **Real-World Data Use Case**                  | Data loaded, both sorts applied, insightful analysis | Data loaded, both sorts applied | Data loaded, one sort applied | Data not loaded or sorts missing |
| **Adaptive Insertion Sort (Binary Search)**   | Correct implementation, comparison with classic, timing shown | Correct implementation, minor issues | Attempted but not working fully | Not attempted or incorrect |
| **Code Quality & Documentation**              | Code is clean, modular, well-documented | Code is readable, some comments | Code is somewhat readable | Code is hard to read or undocumented |
| **Wrap-up Questions**                        | All questions answered insightfully | Most questions answered well | Some questions answered | Few or no questions answered |

---

**Scoring Guide:**  

- 25–28: Excellent  
- 20–24: Good  
- 15–19: Satisfactory  
- <15: Needs Improvement

**Comments:**

- Encourage students to experiment with different datasets and input sizes.
- Reward clarity in code and explanations, not just correctness.
