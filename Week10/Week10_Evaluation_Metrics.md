# Week 10 Lab - Evaluation Metrics

## Evaluation Criteria

The lab will be graded out of **100 marks**.  

---

### Part A: Graph Construction & Visualization (10 marks)
- **Graph creation with nodes & edges (5 marks)**  
  - Graph constructed correctly with required nodes/edges.  
  - Edge weights assigned properly.  
- **Visualization (5 marks)**  
  - Graph displayed clearly with node labels and edge weights.  

---

### Part B: BFS & DFS Implementations (25 marks)
- **BFS traversal (10 marks)**  
  - Correct traversal order.  
  - Efficient implementation (use of queue).  
- **DFS recursive (5 marks)**  
  - Correct recursion-based traversal.  
- **DFS iterative (5 marks)**  
  - Correct stack-based traversal.  
- **Comparison (5 marks)**  
  - Proper understanding and explanation of differences in orders.  

---

### Part C: Traversal Visualization (10 marks)
- **Stepwise visualization (10 marks)**  
  - Each step highlights the current node.  
  - Traversal order is correctly reflected.  

---

### Part D: Applications of BFS/DFS (25 marks)
- **Connected components (5 marks)**  
  - Correct identification of components.  
  - Each component returned clearly.  
- **Cycle detection (10 marks)**  
  - Works for both undirected and directed graphs.  
  - Correct detection (true/false).  
- **Shortest path in unweighted graph (10 marks)**  
  - BFS correctly finds the path.  
  - Path visualization/clear output shown.  

---

### Part E: Topological Sorting & Scheduling (20 marks)
- **Topological sort using Kahn’s Algorithm (10 marks)**  
  - Correct implementation.  
  - Handles cycles properly (returns None or similar).  
- **Course scheduling problem (10 marks)**  
  - Graph modeled correctly from prerequisites.  
  - Valid schedule produced (or impossibility detected).  

---

### Code Quality & Documentation (10 marks)
- **Code readability (5 marks)**  
  - Clean, modular functions.  
  - Consistent naming conventions.  
- **Documentation & observations (5 marks)**  
  - Markdown cells explain results.  
  - Clear interpretation of outputs.
