# Capstone Project Scope

## Project Title: Applied Data Structures in Python

## Introduction

This capstone project challenges student teams (2–3 members) to apply advanced data structures and algorithms learned in the course to solve a real-world problem. The goal is to design and implement a small, well-engineered Python library or tool that leverages at least two key data structures or algorithms from the curriculum. Example ideas include a graph-based route planner, a heap-based task scheduler, or a dynamic-programming puzzle solver.

By the end of the project, teams will demonstrate their ability to design, implement, test, document, and present a professional-grade software artifact.

---

## Scope

- **Domain Choice:** Teams will choose a real-world problem domain relevant to them (e.g., transport, gaming, scheduling, finance).
- **DS/Algorithm Use:** Must use at least **two** distinct data structures or algorithms covered in the course.
- **Software Design:** Focus on clean, modular, well-documented code, demonstrating sound OOP and design principles.
- **Team Collaboration:** Use GitHub Classroom for version control, code reviews, and CI.
- **Testing:** Implement thorough unit tests with `pytest` or similar.
- **Documentation:** Produce professional-level technical writing describing design choices, implementation, testing, and evaluation.

---

## Timeline

- **Week 7:** Submit a one-page proposal outlining:
  - Problem statement
  - Chosen data structures/algorithms
  - Expected dataset/source of data
- **29 Jul:** **Proposal feedback checkpoint** – Teams receive instructor feedback on proposals.
- **Week 10:** Mid-sprint code review and a 5-minute progress demo
- **26 Aug:** **Mid-sprint review checkpoint** – Formal review and feedback on progress.
- **Week 14:** Final demo day and repo freeze

---

## Expected Deliverables

1. **GitHub Classroom Repository**
   - Full codebase with clear structure
   - Unit tests with `pytest`
   - GitHub Actions CI configuration
   - README file explaining setup, usage, and project details
   - License file

2. **8-Page Technical Report (IEEE Format)**
   - Problem motivation and domain
   - System architecture and design
   - Data structures/algorithms used
   - Code implementation highlights
   - Testing approach and results
   - Evaluation/discussion
   - References

3. **5-Minute Demo Video (Link)**
   - Explains the problem and domain
   - Shows key features of the tool/library
   - Demonstrates functionality and design
