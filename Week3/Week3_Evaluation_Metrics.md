# Week 3 Lab Evaluation Metrics

Total Marks: **100**

---

## 1. Code Quality and Structure (20 Marks)

- **Modularization (5 marks):** Functions are well-defined and logically separated.
- **Code Readability (5 marks):** Clear variable names, logical flow, appropriate comments.
- **No Redundancy (5 marks):** Avoids repetitive code, follows DRY (Don't Repeat Yourself) principles.
- **Error Handling (5 marks):** Proper exception handling or validation where necessary.

---

## 2. Logic & Correctness (30 Marks)

- **Core Functionality (15 marks):** Implements the required logic correctly as per the lab task.
- **Edge Case Handling (5 marks):** Robust implementation that works for corner cases.
- **Intermediate Output Checks (5 marks):** Proper use of print/debug/plots to verify steps.
- **Accuracy of Results (5 marks):** Final output is correct and validated.

---

## 3. Evaluation and Analysis (20 Marks)

- **Metric Calculation (10 marks):** Implements evaluation metrics like accuracy, precision, recall, F1-score correctly.
- **Interpretation (5 marks):** Provides insight or brief analysis of the obtained results.
- **Comparison or Justification (5 marks):** Justifies model or metric choices with evidence or comparison.

---

## 4. Documentation & Explanation (15 Marks)

- **Markdown Cells (5 marks):** Clear explanation of each section using Markdown.
- **Step-by-step Reasoning (5 marks):** Shows reasoning or intuition behind code blocks.
- **Citations or References (5 marks):** References to sources, if external techniques/libraries used.

---

## 5. Innovation or Extension (Optional Bonus: 5 Marks)

- **Extra Exploration:** Additional exploration or optimization beyond the minimum requirement.
- **Novel Techniques:** Use of a novel approach not covered in class.

---

## 6. Submission Guidelines (15 Marks)

- **File Structure (5 marks):** Notebook is clean, properly ordered, and runs top to bottom.
- **Output Visibility (5 marks):** Outputs are clearly visible and not hidden or suppressed.
- **Reproducibility (5 marks):** Can be run without modification; all dependencies included.
